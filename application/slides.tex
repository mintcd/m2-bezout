\begin{frame}{PhD Project}
  \begin{center}
    Reasoning on $\underbrace{\text{Quantitative Properties}}_{\substack{\text{bounds of success/failure prob.,} \\ \text{execution time,} \\ \text{size bound of variables}}}$ of Programs with an $\underbrace{\text{Algebraic Approach}}_{\substack{\text{Kleene algebra with tests}}}$
  \end{center}

  A Kleene algebra with tests (KAT) is a Kleene Algebra (an axiomatization of regular expressions) extended with a Boolean subalgebra.

  Programs can be encoded as KAT expressions:
  \begin{align*}
    \textbf{if} \ b\  \textbf{then}\ p\ \textbf{else}\ q\ \quad & \text{ as } \quad bp+\bar{b}q   \\
    \textbf{while} \ b\  \textbf{do}\ p \quad                   & \text{ as } \quad (bp)^*\bar{b}
  \end{align*}

  For example we can prove Loop Unrolling equivalence
  $$\textbf{while } b \textbf{ do } p \quad\equiv\quad \textbf{if } b \textbf{ then } (p; \textbf{while } b \textbf{ do } p) \textbf{ else skip}$$ by proving algebraically
  $$(bp)^*\bar{b} = b p ((bp)^*\bar{b}) + \bar{b}. \text{ (factor RHS, then use $1+xx^* = x^*$) }$$
\end{frame}

\begin{frame}{PhD Project - Contexts and Motivations}
  KAT subsumes the traditional \textit{Hoare logic} (HL) in checking input-output properties (\textit{what} a program does) \footnote{Kozen, D. (2000). On Hoare logic and Kleene algebra with tests.}.

  KAT is worth studying for its convenience in checking equivalence (shown above). For HL, given $C_1$ and $C_2$ one has to prove $\{P\} C_1 \{Q\}$ and $\{P\} C_2 \{Q\}$ separately for every properties $P$ and $Q$.

  HL has been extended to \textit{Graded} HL for intensional, quantitative properties (\textit{how}) e.g., $\{P\} C \{Q\}_\beta$ (starting with $P$ satisfied, executing $C$ leading to $\neg Q$ satisfied with probability at most $\beta$) \footnote{Gaboardi, M. et al. (2021). Graded Hoare logic and its categorical semantics.}.

  KAT has been optimized and extended successfully to approximate Guarded KAT (aGKAT) for probabilistic properties \footnote{Gomes, L., Baillot, P., \& Gaboardi, M. (2025). A Kleene algebra with tests for union bound reasoning about probabilistic programs.}.
\end{frame}

\begin{frame}{PhD Project - Goal and Fruitfulness}
  \textbf{Goal:} Drawing from KAT and Graded HL, to develop a general framework of \textit{Graded KAT} to formalize quantitative resource bounds.

  \vspace{0.5cm}

  \textbf{Fruitfulness:}
  \begin{itemize}
    \item Theoretical advancement.
    \item Targeting practical coding patterns (programs are in polynomial time, \texttt{for} loops are preferred when possible), a matured theory can be integrated into automated verification tools (e.g., a linter).
  \end{itemize}
\end{frame}

\begin{frame}{PhD Project - Challenges}
  What is common among the desired properties? Relations are not always trivial, e.g.,
  \begin{itemize}
    \item In analysis of algorithms, the number of comparisons of a sorting algorithm intuitively relates to its execution time.
    \item It is not the case for lower bound of success/failure probability and upper bounds \footnote{Gomes, L., Baillot, P., \& Gaboardi, M. (2025). A Kleene algebra with tests for union bound reasoning about probabilistic programs.}.
  \end{itemize}

  With a group of properties that have a common structure, how to design axioms and a satisfying semantics?

  \textit{This is an iterative progress.}


\end{frame}

\begin{frame}{PhD Project - Plan}
  \textbf{First phase} (6 months): Drawing from GKAT, to develop a theory for execution time, by proposing axioms and experimenting with examples and counterexamples.

  \textbf{Second phase} (9 months): To develop a theory that subsumes the first phase and aGKAT.

  \textbf{Third phase} (6 months): To develop a semantics for the theory in the second phase, drawing from the categorical semantics of Graded HL.

  \textbf{Long-term}: To iterate when other resource bounds are considered. Then to adapt for relational properties (e.g., equivalence).
\end{frame}
